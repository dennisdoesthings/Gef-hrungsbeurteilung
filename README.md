# Gefährdungsbeurteilung

Browser-Tool für Gefährdungsbeurteilung und Sicherheitskonzept von Veranstaltungen
in Versammlungsstätten. Reines HTML/CSS/JS – `index.html` per Doppelklick öffnen,
keine Installation, kein Server.

## Funktionen

- Gesamtkatalog mit 58 Gefährdungen (Messe, Kongress, Tagung, Technik, Strom), frei erweiterbar
- Risiko und Restrisiko (E × S), Hinweis bei unzureichender Maßnahme
- Suche, Sortierung, Filter nach Bereich, Risikostufe und Feld der Risikomatrix
- Interaktive Risikomatrix (Risiko / Restrisiko) mit Anzahl je Feld
- Maßnahmenplan mit STOP-Kennzeichnung, Verantwortlichen, Terminen und Überfällig-Markierung
- Konzeptteile Ordnungsdienst, Sanitätsdienst, Brandschutz sowie Notfallszenarien
- Löschen, Import und Zurücksetzen lassen sich rückgängig machen
- Export/Import als JSON, Export als CSV (Excel), Druck / PDF
- Autospeicherung im Browser (localStorage)
