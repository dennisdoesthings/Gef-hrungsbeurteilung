# Branding / Logo

Hier wird das Logo abgelegt, mit dem Dokument und Ausdruck gebrandet werden.

## So geht's

1. Logo als PNG (am besten mit transparentem Hintergrund) hier ablegen.
2. Datei **exakt** so benennen:

   ```
   logo.png
   ```

   → vollständiger Pfad: `branding/logo.png`

3. Seite neu laden. Das Logo erscheint dann automatisch
   - oben rechts im Kopf (am Bildschirm) und
   - oben im gedruckten Dokument / PDF (für Kunden).

## Hinweise

- Empfohlene Höhe ca. **80–160 px**, Breite frei (wird proportional
  auf max. Höhe skaliert).
- Ist keine `logo.png` vorhanden, bleibt der Platz einfach leer –
  es gibt keinen Fehler und kein Platzhalterbild.
- Andere Formate (z. B. `logo.jpg`, `logo.svg`) werden nicht
  automatisch geladen. Bei Bedarf einfach in `logo.png` umbenennen
  bzw. exportieren.
